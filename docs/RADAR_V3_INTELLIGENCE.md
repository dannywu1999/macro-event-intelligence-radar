# Radar V3: event intelligence and bilingual markets

## Visitor workflow

The map remains before the independent Prediction Market Watch. Open **Event Intelligence** on an event to inspect the original headline/references, proposition-level Official Evidence, source observation/check timestamps, timeline, context geography/institution explanation, eligible linked expectations, MacroView preview and Reality Replay. Map navigation opens that same detail.

Chinese Watch question summaries are reviewed presentation text, matched by **exact market ID and exact original question**. The 20 reviewed saved questions cover Fed policy, Section 232 tariffs, WTI thresholds, crude all-time high and US/Iran ceasefires. Changed/unreviewed questions remain prominently in English with only safe category/terminology hints. English and provider settlement metadata remain directly accessible. Only literal Yes/No outcomes are translated; other outcome identities are unchanged.

## Four existing capabilities made accessible

| Capability | Existing implementation/data | Interaction | Truth boundary |
|---|---|---|---|
| Evidence and chronology | adapter canonical membership, linked propositions and typed timeline | one event detail → evidence reference / timeline | Official confirms only a proposition; News event stays unverified |
| Source Intelligence | article source/report/observation fields; optional per-source acquisition metadata | inspect exact article and last successful check | input availability is separate from source connectivity; missing health stays Unknown |
| MacroView knowledge state | macroview preview snapshot + evidence/provenance hashes | inspect facts, linked expectations, missing inputs and reference | PREVIEW is not FROZEN; no historical knowledge claim |
| Reality Replay | recorded-observation store and read-only replay API | explicit event + ISO system-time cutoff | no fake slider; no private database connection; unavailable/no-history remains explicit |

No backend evidence schema, linker threshold or source record is rewritten. Independent Watch markets do not become event probabilities. PUBLIC recording stays disabled. Existing frozen snapshots retain their bytes; current API serves previews, not persisted freezes. Valid runtime ledger replay remains available through the existing explicit configuration, otherwise loading replay returns Unavailable. Market Reality remains absent unless eligible public observations exist; no private OHLC or empty simulated charts are added.

## Validation scope

Focused tests execute the actual frontend and API, plus existing Official/expectation, MacroView, observation/replay and geography contracts. Browser acceptance uses saved real provider snapshots and explicitly labels their age; it is not a fresh provider/production-monitoring test. No deployment is performed by this batch.
